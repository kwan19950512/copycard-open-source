# 拷卡 · macOS 试用版

面向摄影素材和普通文件的单向拷贝工具。最低 macOS 14。不是同步工具，不删除来源，不提供格式化功能。

## 怎么使用

首次打开或试用版更新后，会显示“集中设置文件访问”。点击“选择常用目录并授权…”，可按 Command 一次选桌面、文稿、素材盘等根目录；相应位置会记住并显示在侧栏。顶部“访问权限”可随时重新打开管理。记录目录位置不等于获得完整磁盘访问，也不能绕过 macOS 的系统授权。当前临时签名在更新后可能需要集中重新选择；正式签名身份配置后才有条件改善跨版本权限延续。

从 [0.2.17 发布页面](https://github.com/kwan19950512/copycard-open-source/releases/tag/v0.2.17) 下载 macOS 压缩包，解压后打开拷卡 App。可以把 App 复制到自己的“应用程序”文件夹。此版本是本地签名试用包，未经过 Apple 开发者公证；其他电脑可能需要在系统设置中由使用者手动允许打开。

1. 打开来源文件夹，选中要复制的文件或文件夹。可用 ⌘ 多选、⌘A 全选。
2. 点“复制所选”或按 ⌘C，上方会显示已记住的来源；再打开目标位置，点“粘贴到这里”或按 ⌘V。也可点“选择目标拷贝…”。文件拖放建任务已关闭，轻微拖动不会创建拷贝。
3. 核对预览中的来源、目标、最终目录和空间。选中文件夹时会保留外层文件夹名；整卡请确认卡名就是需要的外层目录。
4. “加入队列”不会开始写入。点击“开始”才执行复制和完整目标读回校验。
5. 完成后在任务详情查看报告。来源需要自己手动推出，App 不自动推出，也不格式化卡。

准备阶段可点“取消准备”；预览可点“取消预览”或按 Esc；已加入队列的任务点“取消任务”，会保留已写入的文件。当前预览没有确认或取消前，新粘贴不会替换它。粘贴回原位置会直接提示换一个目标，不生成自拷贝预览。任务卡片始终显示“来源 → 目标”，不需要展开详情才能辨认方向。

默认是单个浏览窗口，可以新开窗口；“并排浏览”可把两个窗口合并，之后也能拆开。图标视图底部可调图标大小，另有分栏视图。底部任务队列由所有窗口共享，能折叠。

图标视图支持从空白处拖出选框，Command / Shift 可追加框选；单击空白处取消选中。文件夹与文件使用 macOS 类型图标，不为图标读取素材内容。右键文件夹、侧栏位置或底部路径层级，可在新窗口打开；右键浏览空白可新开当前目录。底部路径各级可点击跳转，顶部不再单独放“新窗口”按钮。智能整理位于窗口顶部，未配置时旁边直接提供“配置 AI”。

## 校验、冲突与恢复

- 所有选中的普通文件都做内容校验，包括 XML 和其他非视频文件。默认 XXH64BE，设置可选 MD5，切换只影响新任务。
- 复制后重新打开目标文件，完整读回并比较摘要。两种算法用于发现复制错误，不是防恶意篡改签名，也不判断源视频能否播放。
- 同名文件完整核对；相同则不重复写入，不同则保留原文件、列为冲突。其他文件继续执行，不自动覆盖。
- 暂停、取消都保留已写入的内容。未完成文件使用隐藏的 `.copycard-…partial` 名称，不冒充成功素材。首版恢复会重写未完成的单个文件，保留旧临时文件；已完成文件重新核对但不重复写入。旧临时文件仍占空间，不自动清理。
- 重新打开 App 或重连设备不会自动恢复任务，需要点击继续。目标卷与目录身份变化时需重新选择目标，不会只凭同名磁盘继续写入。
- 关闭浏览窗口不会结束后台任务；退出 App 时有活动任务会先询问暂停并保存。
- 同一物理设备默认排队，独立设备可同时运行。高级设置可调整并行数或手动允许同盘并行，后者可能更慢。
- 空间检查按剩余待写文件计算，并预留至少 64 MiB；系统“可清理空间”仅展示，不当成已经释放。真正写入时仍会处理磁盘满和读写错误。

## 报告和历史

目标的 `拷贝校验报告/` 中有文字摘要和 JSON 明细。目标根目录有可携带的 MHL 1.0 清单（XXH64BE 或 MD5），只包含校验通过的文件。它不是 ASC MHL 2.0 历史链。

本机任务历史在 `~/Library/Application Support/CopyCard/jobs.json`，目标不在线时也可查看。报告写入失败不抹掉已校验结果，可在设备恢复后补存。若更换整批目标，新目标按整批重新处理，旧目标内容不删除。

## 智能整理（可选）

在设置中自行填写兼容 OpenAI Chat Completions 协议的 HTTPS **完整请求地址**（通常以 `/chat/completions` 结尾）、模型名称与 API 密钥，点击保存。密钥保存到本机钥匙串；不同地址分别保存密钥，程序不内置共享密钥或付费账户。

选中来源后点击“智能整理”，先看实际发送的目录元数据，再确认发送。每批最多 500 条、200 KiB；只含相对目录、文件名、大小、少量白名单相机 XML 字段，不上传媒体内容或绝对路径。目录、文件名本身也可能包含项目信息，请在预览里核对服务地址与发送内容。请求费用由自己的 API 账户承担。

AI 仅建议分组：设备日期不能作为唯一依据。可改名、拆分、合并、移动文件归属，再选目标并检查最终路径与容量。确认后只加入待开始队列。无网络、未配置或已知服务不可用时智能入口禁用，手动功能不受影响。

## 已知范围

- 首版每项任务一个目标，可建立多项任务备份到不同目标；不做镜像同步或删除。
- 保留文件内容和选定相对目录；不复制符号链接、Finder 替身及其他特殊对象，不承诺扩展属性、ACL 或原始文件时间戳完全复刻。
- 来源含快捷链接或特殊对象时，预览会明确解释不能复制并校验的原因。可主动点击“排除上述项目，继续其他文件”；排除对象保留在来源，预览、历史和文本/JSON 报告注明“未复制、未校验”，不会出现在 MHL 校验通过清单。普通 `.command` 脚本可以像其他普通文件一样复制并校验；扩展名本身不会被拦截。
- “所选范围”以预览时的清单为准。预览之后新增的文件不会自动混入任务；需重新选择。原有条目发生变化会被拦截。
- 当前交付为试用版。外接读卡器、多种文件系统、真实拔盘及各家 AI 服务仍需在副本素材上验收。

## 开发与验证

只依赖 macOS 系统框架与 Xcode，不安装全局依赖。

```sh
swift test
bash scripts/build-app.sh release universal
bash scripts/verify-release.sh
```

在有独立 Pomfort `mhl-tool` 时，可设置 `MHL_REFERENCE_TOOL=/path/to/mhl` 再运行测试以复核互操作性；没有该工具时该项测试明确跳过。参考工具来源与格式依据见 `Tests/CopyCoreTests/Fixtures/README.md`。

开发调试包可使用 `COPYCARD_AI_UI_FIXTURE=/path/to/generated-fixture` 环境变量打开仅用于界面验收的模拟 AI 分组窗口。该入口不会联网、不读密钥，且不编入 release 版本。
